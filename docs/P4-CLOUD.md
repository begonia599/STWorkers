## 实际验证

不打开用户聊天界面，不读写模型配置、聊天或设置，也不发送真实模型请求。
通过原始 HTTPS API 测试 Cloudflare 到 GitHub 的真实下载，不使用本地网络回放。
本轮没有重新执行云端原版浏览器或完整 MVU/模型工作流。

1. 更新前后检查登录保护、原插件 manifest、阶段及前端文件哈希；新增写接口的 CSRF/来源保护通过。
2. 先确认 global 作用域没有插件，再安装两款锁定插件的测试副本；local 随包插件始终优先。
3. 固定提交查询和同提交更新通过；切换到真实父提交生成另一份归档，再回退到锁定提交通过。
   不是制造上游移动分支来验证一次真实新发布，也不代表自动更新全场景通过。
4. 临时将 local 分发改为完全相同提交的 R2 归档，核对运行入口字节后恢复 bundled 指针。
5. 两款 global 测试副本已经卸载；D1 确认 current/previous 均为空、待清理对象数量为 0。

## CPU 与费用边界

通过已有 OAuth 只读查询 GraphQL 成功，没有启用 Workers Logs 或购买指标服务。
统计窗口为 UTC 14:10:33 至 14:15:24，39 个按秒/状态分组的统计桶：
47 次服务端调用、38 次 subrequest、平台统计错误 0。

从 GraphQL schema 实际核对 `cpuTimeP50` / `cpuTimeP99` 单位是微秒。
部分桶的 CPU P99 换算后为 72.990、83.232、93.117、224.473、241.402、247.021 ms。
247.021 ms 是本窗口“最高统计桶的 P99”，不是全局 P99、客户端耗时或单请求最大值。
按脚本及时间窗口统计可能混入同期其他请求；本轮没有成功取得逐请求 tail，不能把每个值
精确归到某一个测试接口，也不能把平台错误 0 当成客户端没有超时。

2026-09-10 核对 Cloudflare 官方限制：Free 的 HTTP CPU 预算为每请求 10 ms，
isolate 内存为 128 MB。当前数据不满足宣称免费资源验收通过的条件；少量请求成功不是长期保证。
没有取得每请求内存实测值。账户订阅查询仍为 403，不能确定账号套餐或承诺账单一定为零。

下一阶段优先调整安装和大文件分发路径，避免把整包解析/入口解压校验集中在一个 Worker 请求；
继续保持原版安装入口和 Git 版本契约。不得把升级付费套餐作为默认解决方案。
