## 必需回归样例

1. 原生角色卡、预设、宏、正则和世界书共同生成。
2. EJS 使用全局、聊天和消息数据生成提示词。
3. 酒馆助手脚本调用生成并修改消息。
4. HTML 状态栏按钮更新变量，刷新后保持结果。
5. MVU 类变量脚本在重生成与切换回复后恢复对应分支状态。
6. 脚本读写世界书、预设或角色字段并重载。
7. 两插件共同启用、事件顺序一致、导出再导入无字段丢失。

测试数据必须来自合成样例或用户明确提供的非敏感副本。
不得自动读取原项目聊天、密钥或私人角色卡作为测试数据。
