# 目标冻结

冻结日期：2026-09-08。除非用户明确改变目标，后续实现不得自行扩大或缩小这些边界。

## 产品定位

STWorkers 是保留原版 ST 使用体验、核心提示词行为和社区生态入口的云端发行项目。
Workers 是部署方式，不是重写简化聊天界面的理由。
默认每位用户部署到自己的 Cloudflare 账号，不经营公共多租户服务。

## 必须保留

1. 原版前端页面、主要操作入口、目录和模块接口。
2. 角色卡、用户人设、预设、宏、正则、世界书。
3. 聊天历史、编辑、重新生成、停止、切换回复、导入导出。
4. 支撑核心功能的事件、变量、斜杠命令、Token 计数及聊天元数据。
5. 酒馆助手和 ST-Prompt-Template 的实际角色卡、脚本和模板工作流。
6. 数据可迁移、可备份；未知扩展字段不能静默丢失。

“核心”表示选择核心能力，不表示把每项能力改成不兼容的简化替代品。
社区脚本调用明确排除的服务时，该部分不在支持范围内。

## 明确不考虑

- 本地模型管理。
- 在 Cloudflare 上进行模型推理，或为此引入常驻服务、容器、GPU。
- 语音功能，包括语音生成、识别及相关服务集成。
- 生图功能及相关服务集成。
- 依赖付费 Cloudflare 计算完成以上功能的替代路线。
- 公共注册、共享模型额度、公共多租户平台。

不开发这些服务，不等于无差别禁止角色卡的普通浏览器 HTML、图片或脚本渲染。

## 插件策略

- 酒馆助手是项目成立的前提，不能把兼容性推迟为可选增强。
- 原版前端插件仍在用户浏览器执行，不迁入 Worker 执行用户脚本。
- 在线 URL 安装、版本查询、手动更新是保留的产品方向。
- 原版 Git 文件目录实现可以替换，不要求在 Worker 内运行原生 Git。
- 锁定提交用于回归测试；不永久封锁用户更新或导入社区脚本。
- 不能凭插件面板显示、少量 API 存在就声称兼容完成。

## 免费资源与上手

- 以免费额度、资源数量、请求量、CPU、存储和首次开通门槛共同验收。
- 不把“有免费额度”描述成“无限免费”，不默认替用户启用付费能力。
- 模型接口由用户配置，模型服务费用独立计算。
- 2026-09-10 用户确认：模型地址直接在原版界面填写，不设置强制域名白名单，
  不要求普通用户为连接或更换模型服务编辑部署变量、重新部署或完成额外审批。
  保留 HTTPS/地址格式校验、登录保护、CSRF、凭据隔离与禁止自动重定向。
- 目标流程：授权部署、建立访问保护、配置模型、导入资料、开始聊天。
- 登录及改密允许用户自行设置非空密码，不附加强制 24/12 字符或字符组合要求。
  复用原版登录页不等于原样移植认证后端；Workers/D1 单所有者实现与原版差异必须明确说明。
- D1、对象存储、初始化数据和升级迁移应尽量自动化。
- Cloudflare 账号授权、资源开通、可能的计费资料要求必须在发布前实测记录。

## 验收原则

2026-09-11 用户确认简化上手目标：首次 Fork、按需编辑 `plugins.txt`、完成账号授权及部署；
以后加插件只编辑清单并运行构建部署，不让普通用户手算哈希或编辑打包脚本。
默认保留酒馆助手和 EJS；用户清单不是项目维护者审批的插件白名单。
版本锁定和公开插件打包由构建程序完成。账号授权、实际初始化门槛与未适配插件仍需如实说明。
清单模块应可供现有 Actions 及未来 Cloudflare 原生构建入口复用；
新增简化目标不代表免手填 Cloudflare Token 的首次部署入口已经通过验收。

2026-09-10 用户确认当前推进顺序：先用 GitHub Actions 接替开发电脑执行
“准备插件、打包、部署”，沿用已验证的随包预装方式。
在线安装后端优化留待后续细化，不作为本阶段先决条件；不删除原在线安装产品方向，
也不把这个阶段调整解释为免费资源或完整生态验收已经通过。

分别记录：源码审查、单元测试、原版行为对照、本地浏览器验证、真实 Workers 验证。
前一种证据不能替代后一种。
最终以实际发给模型的提示词、持久变量、角色卡交互和重载恢复为准。
