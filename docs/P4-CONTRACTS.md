## 支持范围

- 原版安装弹窗填写公开 GitHub 或 GitLab 仓库根地址；可指定分支、标签或完整提交 ID。
- 支持这些平台上的普通前端扩展，不按仓库所有者或插件名称设置白名单。
- 保留原版发现、安装、版本、更新、分支列表、分支切换、卸载接口。
- 增加明确的上一版回退操作，按钮在原扩展管理面板内；不会把回退版本伪装成 Git 分支。
- 支持 local/global 安装作用域及 local 优先加载。跨作用域 move 尚未实现，面板隐藏该入口。
- 私有仓库、SSH、其他 Git 托管平台、自建 GitLab、子模块和需要服务端编译的扩展尚不支持。
- 插件仍在浏览器运行，安装过程不执行 npm、构建脚本、Git hook 或用户服务端代码。

现有随部署包附带的酒馆助手和 EJS 可转为在线管理，也可回退到仍存在于当前部署包中的原版本。
卸载会留下版本化的删除记录，避免原静态插件在刷新或重新部署后自动复活。

## 原版操作

1. 扩展面板选择“安装扩展”，填写仓库根地址；不需要重新部署 Worker。
2. 确认原版第三方代码风险提示。安装成功后，原版发现和加载流程继续执行。
3. 管理扩展时查看版本；有更新时使用原来的更新按钮。
4. 更新后刷新页面加载新代码；有上一版时显示回退图标。
5. Workers 卸载接口不主动删除聊天、变量或扩展设置。前端仍执行原版 delete hook，
   可选的 clean hook 仍由用户明确选择；插件自己的 hook 行为不在后端数据保留保证内。

第三方脚本有与原版相同的浏览器权限，不是沙箱。能安装不等于所有扩展的全部功能都已兼容。
执行本项目明确排除的语音、生图、推理或本地文件服务仍会失败。

## 下载与存储

- 通过平台公开 API 解析实际分支、标签及提交，再按完整提交 ID 下载 ZIP。
- 不转发实例密码、Cookie、模型密钥或用户提供的请求头。拒绝自动重定向。
- 每次远端请求有超时和读取上限，限流或下载失败明确返回错误，不自动反复重试。
- 使用已有的 yauzl 库检查 ZIP 目录及本地头，不手写 ZIP 解析器。
- 限制压缩包 25 MiB、单文件 25 MiB、声明展开总量 128 MiB、5000 个条目、索引 768 KiB。
- 拒绝目录穿越、符号链接、加密 ZIP、大小写重名、重叠文件区域及不支持的压缩方式。
- 安装时验证 manifest 和声明的 JS/CSS/语言文件；其余文件在读取时校验展开大小和 CRC。
  不是安装时已经完整解压并验证了仓库中所有文件。
- 完整 ZIP 和索引各存一个私有 R2 对象；D1 仅记录当前版本、上一版及待清理对象。
- 文件请求沿用 `/scripts/extensions/third-party/<目录>/...`；从 R2 按范围读取对应文件，
  使用原生 zlib 有界解压。源码通过同目录 `__source.zip` 提供，并且也需要鉴权。
- workerd 的原生解压缓冲区扩展在部分文件大小上会超过精确输出上限；增加 64 KiB
  有界余量后仍逐字节长度及 CRC 校验。不是取消大小上限或相信归档声明。
- 无新增数据库表或迁移，不改变现有账号、聊天和密钥的存储方式。

## 更新与异常

下载、结构检查、声明入口校验及 R2 写入全部成功后，才用 D1 的 revision 条件更新切换版本。
读者不会读到一个逐文件覆盖到一半的归档。同一页面在更新过程中发出的多个请求不是
跨请求事务；更新后仍需刷新页面，不承诺热替换已经执行的脚本。

明确的并发冲突会清理失败一方新上传的对象；不会删除胜出版本。
如果数据库确认消息丢失、无法判断写入是否已经成功，则保留对象，防止误删实际已提交的版本。
这种不确定故障可能留下未引用的对象，目前没有自动扫描并回收所有孤立对象的后台任务。

正常更新只保留当前和上一版。淘汰对象清理失败会记录在 D1，可通过
`POST /api/extensions/cleanup` 和原作用域/目录名重试，包括已经卸载的插件。
待清理对象过多时阻止继续更新，避免在故障状态下无限积累。

标签和固定提交不会被说成一个不存在的分支；内置固定包原先的 Git 分支未知时也保持为空。
分支/标签版本检查有最多 60 秒的短缓存，更新操作重新解析远端，不依赖检查缓存决定下载内容。
已安装并验证的完整固定提交不会变化，版本查询与同提交更新直接返回已记录的结果，不再发起网络请求。
分支列表最多读取 300 条，超出时返回错误而不是悄悄截断为完整列表。
跟踪分支的远端检查失败时返回真实错误，不伪称最新版；当前面板的回退图标由版本查询结果
决定，远端故障时可能不显示。回退 API 本身只依赖本实例存储，不需要访问 Git 平台。

```powershell
node cloudflare/scripts/check-p4-local.mjs <提供-playwright-的-package.json> <Chrome-可执行文件>
```

可选第三个位置参数为已有归档父目录，其中有 `<插件ID>/__source.zip`；
