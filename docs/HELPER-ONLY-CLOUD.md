  `preparePluginSelection`、`packagePlugins`、`build-assets` 与 `checkAssets`。

  未更新插件，未运行第三方安装或编译脚本。
- 原 `AUTH_PASSWORD` 备份通过实际登录验证，原 `DATA_KEY` 备份成功解密
  已存模型凭据；解密只在内存验证，未输出明文，也未调用提供商。

  使用非强制服务删除；控制面确认其不存在后，同名重新上传。
- D1/R2 保留，未新建或清空存储，未重复迁移；首次上传即带回原两把密钥。
  原网址、登录名和密码不变。没有订阅或套餐变更。
- 删除前插件记录为 local bundled 指针及已卸载的 global 副本；
  没有在线安装的活动版本覆盖预装清单。因此不修改插件记录或设置即可停止加载 EJS，
  历史归档备份仍保留于原存储。

不能用此结果声称其已支持删除后的首次初始化。

## 验证结果

- 247 项测试通过，无失败或跳过；普通构建及带原 secret 文件的单插件 dry-run 通过。
- 资源清单为 632 个实际文件，45,467,984 字节；Wrangler 日志计数为 681。
  真实上传报告为 630 个上传文件、2 个已有文件。Worker 652.49 KiB，
  gzip 125.88 KiB，平台报告启动时间 44 ms；不据此推算免费额度或端到端性能。
- 本地桌面与全新手机会话均加载 Helper，无 EJS 请求、在线安装或 Worker 插件下载。
  合成全局变量实际落库，桌面刷新及手机新会话恢复通过，隔离 R2 无对象。
- 初版测试脚本未等待原版欢迎向导及 `settingsReady`，产生提前保存/重载误判。
  修正等待并核对真实落库后通过，未修改产品代码来绕过该断言。
- 云端鉴权及存储绑定核验通过；15 条记录的数量、分类、ID/版本/长度指纹未变。
  这不是逐字节完整备份或恢复演练。两把密钥备份未变，原加密凭据仍可解密。
- 云端发现仅有 `regex`、`quick-reply` 和 `third-party/JS-Slash-Runner`。
  Helper manifest、JS、CSS 与本地构建字节相同；EJS manifest 与 JS 均返回 404。
- 云端桌面与手机的原版扩展面板及 Helper API 加载通过，EJS 全局对象和资源请求均不存在。
  检查期间拦截模型请求、在线管理及设置写入，不把受控只读冒烟当作完整聊天验收。
  ST 自动保存设置/快捷回复及连接模型时会被测试拦截，截图保留相关提示；
  `QuickReplySet` 被拦截保存产生的 `Failed to fetch` 单独记录，不宣称页面零错误。

单插件不支持依赖 EJS 的卡片部分，灯塔 v1.1 的 EJS 测项不应在本配置下判为应通过。
真实模型、完整 MVU/社区卡、免费资源与 Actions 云端部署门槛继续保留。
