# SillyTavern

LLM Frontend for Power Users

The original [upstream README](../.github/upstream-readme.md) is preserved separately.
The repository homepage uses the [STWorkers README](../README.md).

## Archived Guides

- [Upstream contribution guide](UPSTREAM-CONTRIBUTING.md)
- [Upstream update instructions](UPSTREAM-UPDATE.txt)

These guides describe the original SillyTavern project, not STWorkers deployment.
For this edition, use the [Workers deployment guide](NATIVE-DEPLOY.md) and
[project goals](GOALS.md). The [security policy](SECURITY.md) is also kept in this directory.

Legacy Docker, Colab, Replit, local launch/update, tunnel, account-recovery and
Node server-plugin tools are no longer part of the current distribution.
Their original source remains available at the revision recorded in
[`upstream-lock.json`](../upstream-lock.json).
The Node reference server and helpers used by compatibility tests are retained.
